## Stack y estructura
- **Next.js 15 (App Router) + TypeScript estricto + tRPC + Prisma + PostgreSQL + TailwindCSS**.
- Editor: **BlockNote** (con custom blocks/inline content propios). Iconos de interfaz: **lucide-react** (NO emojis/símbolos en el chrome). Gráficas: ECharts. Índices fraccionales: `fractional-indexing`.
- Repo en el PC: `~/Projects/notiono` (el remoto es `git@github.com:josemp94/notiono.git`, rama `main`).
- **Auth = SOLO SSO (Synology OIDC)**, sin cuentas locales. El alta ocurre en el callback OIDC; primer usuario = admin. Rutas públicas fuera del grupo `(app)`: `/login`, `/s/[token]` (páginas publicadas), `/f/[token]` (formularios públicos), `/api/*`.
- Multiusuario por **workspace** (Membership). `workspaceProcedure` da `ctx.user` y `ctx.workspace`.

## Convenciones (IMPORTANTE, seguir siempre)
- **TypeScript estricto**; `npm run build` debe quedar LIMPIO antes de commitear.
- **Migraciones de Prisma A MANO**: crea `prisma/migrations/<timestamp>_nombre/migration.sql` con el SQL (ALTER/CREATE), y ejecuta `npx prisma generate` tras tocar el schema. NO uses `prisma migrate dev` (el deploy aplica con `prisma migrate deploy`). El SQL debe ser válido para Postgres 16.
- **Un commit por función**, mensaje claro y descriptivo (en español, estilo `feat: ...`). NO hagas push automático salvo que se pida.
- Si editas ficheros con scripts de sustitución de texto, **comprueba que cada sustitución ha coincidido** (un `replace` que no encuentra su patrón no falla, se traga el cambio en silencio: así se coló un commit afirmando algo que no estaba hecho).
- **Marca**: naranja `#ff5c28`; tokens CSS `var(--bg/--fg/--border/--muted/--brand)`; **modo oscuro** por `data-theme` en `<html>` (respétalo en todo, incl. BlockNoteView, modales, BD y páginas `/s/`).
- **Móvil**: nada de controles que solo aparezcan al pasar el ratón — usa la clase **`.al-pasar`** (se esconde al ratón, se ve en táctil); si de verdad es de ratón (arrastrar, tirador de ancho), déjalo escondido. Para agrandar la zona de toque, `.toque` (40×40 en táctil) o `.toque-estrecho` (solo alto). Los menús colgantes ya lo hacen solos por `[data-menu]`. **El margen izquierdo de la tabla es `GUTTER_WIDTH`** (`src/lib/cellText.ts`) y va FORZADO en todas sus celdas: es el punto del que cuelgan las columnas congeladas y, si no cuadra, se ve la tabla pasar por la rendija. Se comprueba a 390 px con un banco de esbuild+Playwright (ver `docs/movil.md`).
- **Iconos**: interfaz/chrome → **lucide-react** (size ~16-18, strokeWidth ~1.75, `currentColor`). Los **iconos de página que elige el usuario son emojis** (PageIcon.tsx) — eso NO se toca, es contenido, como en Notion.
- **Nombres de archivo** al generar/enviar ficheros: SIN acentos, espacios ni caracteres especiales (guiones_bajos) — si no, se rompe el envío por WhatsApp.
- No rompas: SSO, rutas públicas `/s/`, el editor, las BD, el árbol del sidebar.
- **Bloques del editor a la base de datos, siempre por `jsonLimpio`** (`src/server/jsonLimpio.ts`): BlockNote deja `undefined` dentro de arrays (`columnWidths` de las tablas) y Prisma rechaza el guardado entero.
- **Modo seguro** (`src/components/editor/ModoSeguro.tsx`): si una página se colgó la última vez o el editor revienta al pintarla, se abre con su texto sin editor y un aviso. Si cambias cómo se monta el editor en `p/[pageId]/page.tsx`, déjalo dentro de `EditorProtegido`.
